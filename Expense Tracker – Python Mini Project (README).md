# Expense Tracker – Python Mini Project 

## Project Title 

### Expense Tracker (Menu-Driven Python Application) 

##### Project Description 

This project is a simple menu-driven Expense Tracker developed using Python. It allows 

users to record daily expenses, view all expenses, search expenses by category, calculate 

total expenses, and save data to a file. The project is designed as a beginner-friendly mini 

project following core Python concepts taught in class. 

&nbsp;

##### Features 

• Add new expense records 

• View all expenses 

• Search expenses by category 

• Calculate total expenses 

• Save and load expenses from a file 

• Simple and minimal console output 

&nbsp;

##### Concepts Used 

• Functions 

• Lists and Dictionaries (List of Dictionaries) 

• while loop 

• if / elif / else conditions 

• String methods (strip(), title(), capitalize()) 

• File handling 

• Basic input validation 

&nbsp;

##### Data Structure Used 

Expenses are stored as a list of dictionaries: 

expenses = \[ 

&nbsp;   { 

&nbsp;       "date": "01-04-2024", 

&nbsp;       "category": "Food", 

&nbsp;       "description": "Lunch", 

&nbsp;       "amount": 250.0 

&nbsp;   } 

] 

&nbsp;

###### How to Run the Program 

1\. Open the Python file or Jupyter Notebook. 

2\. Make sure all functions are defined. 

3\. Run the program. 

4\. The menu will appear: 

1.View 2.Add 3.Search 4.Total 5.Exit 

5\. Enter the option number to perform the required operation. 

&nbsp;

##### Input Guidelines 

• Date format: DD-MM-YYYY or YYYY-MM-DD 

• Category: Text (e.g., Food, Transport, Education) 

• Amount: Numeric value only 

&nbsp;

##### File Handling 

• Expenses are loaded at the start of the program. 

• Data is saved when the user selects the Exit option.
